## Blogs

The sites is available on link https://risyandi.com/blogs. the sites powered and hosted by Github pages.

### Run locally

Requires Ruby >= 2.7 (3.3 recommended).

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000/blogs/

### Deployment

Pushes to `master` are built with Jekyll 4 by GitHub Actions (`.github/workflows/main.yml`) and deployed to the `gh-pages` branch.
